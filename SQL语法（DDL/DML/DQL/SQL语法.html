[[关系数据库管理系统（RDBMS）中的游标（Cursor）]]

count（）

您的 SQL 语句存在语法错误，具体问题在于 COUNT() 函数缺少必需的参数。在 SQL 中，COUNT() 函数必须指定要计数的内容。

错误原因：

✅ 正确写法（两种方案）：

方案 1：使用 COUNT(*)（推荐）

方案 2：指定具体列名（如 device_id）

📌 关键区别：

方法 作用 是否计数 NULL 值
COUNT(*) 统计所有行数（包括 NULL 行） ✅ 是
COUNT(column) 统计指定列的非 NULL 值数量 ❌ 否

💡 建议：

  1. **大多数情况使用 COUNT(*)**：性能最优且语义清晰（统计行数）
  2. 只有当需要排除 NULL 值时才使用 COUNT(column)

其他聚合函数如 AVG()/SUM() 会自动忽略 NULL 值，无需特殊处理。
